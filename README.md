# Mini Engine

Mini Engine — учебный 3D-движок и редактор сцен, написанный на C++ с использованием OpenGL и Qt.

Проект позволяет создавать и импортировать 3D-объекты, изменять их Transform и материалы, управлять камерой и работать со сценой через редактор.

## Основные возможности

- отображение 3D-сцены через OpenGL;
- Perspective и Orthographic проекции;
- создание Cube, Plane и Sphere;
- импорт моделей формата OBJ;
- поддержка моделей с несколькими материалами;
- загрузка текстур;
- настройка материалов;
- Point Light и Phong lighting;
- Hierarchy объектов сцены;
- Inspector для редактирования свойств;
- выбор объектов мышью;
- Move Gizmo;
- удаление объектов;
- управление камерой;
- отображение Grid и мировых осей.

## Управление

| Клавиша | Действие |
|---|---|
| `W` | Движение камеры вперёд |
| `S` | Движение камеры назад |
| `A` | Движение камеры влево |
| `D` | Движение камеры вправо |
| `Q` | Движение камеры вниз |
| `E` | Движение камеры вверх |
| `F` | Сфокусировать камеру на выбранном объекте |
| `Esc` | Снять выделение с объекта |
| `R` | Сбросить Transform выбранного объекта |
| `G` | Показать / скрыть Grid |
| `X` | Показать / скрыть мировые оси |
| `H` | Показать / скрыть Move Gizmo |
| `L` | Включить / выключить освещение объектов |
| `C` | Показать / скрыть информацию о Camera и выбранном объекте |
| `1` / `P` | Perspective projection |
| `2` / `O` | Orthographic projection |
| `Delete` / `Backspace` | Удалить выбранный объект |

## Управление мышью

| Действие | Результат |
|---|---|
| `ЛКМ` по объекту | Выбрать объект |
| `Alt + ЛКМ` + движение мыши | Поворот камеры |
| Колесо мыши / trackpad | Приближение и отдаление камеры |
| Перетаскивание оси Gizmo | Перемещение выбранного объекта |

## Редактор

Редактор состоит из нескольких основных панелей:

- **Hierarchy** — список объектов текущей сцены;
- **Scene** — основной 3D Viewport;
- **Inspector** — редактирование Transform и Material выбранного объекта;
- **Project** — отображение ресурсов проекта.

Через меню **Create** можно добавить стандартные примитивы:

- Cube;
- Plane;
- Sphere.

OBJ-модели можно импортировать в сцену через открытие файла модели.
